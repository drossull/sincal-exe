# Tipografías de SINCAL Suite

SINCAL registra estas tipografías sólo para su sesión, sin instalarlas de forma
permanente en Windows:

- GT Pressura Regular.
- Roboto Regular para lectura y tablas; Roboto Condensed Bold para títulos.
- Roboto Flex Regular para botones; Roboto Mono Regular/Bold para campos
  numéricos y consola, igual que los roles tipográficos de Cadence. Sus licencias
  acompañan los archivos (`roboto-*-license.txt` y `roboto-license.txt`).
- GTPressura Bold y Helvetica Neue se conservan por compatibilidad. Las
  variantes Roman y Bold que carga la aplicación se distribuyen como TrueType
  con hinting para mejorar el suavizado de Tk en Windows.

Los archivos fueron aportados por el responsable del proyecto. Antes de
publicarlos debe comprobarse que la licencia adquirida permita incorporarlos y
redistribuirlos dentro del instalador de SINCAL.
