# SINCAL Suite 3.0.16 — Proyecto y navegación

- Reorganiza el menú con íconos: Home, Documentación, Proyecto, Comandos en vivo, Generador de armadura, Consulta de proyecto y Diagnóstico.
- Proyecto reúne Archivo, Propiedades, Revisiones, Prospecciones y Mapa de ubicación. Las herramientas relacionadas se presentan en pestañas internas.
- Centraliza informes PDF/TXT, mapas KML/KMZ, DWG, DXF, carpetas y documentos de referencia para reutilizarlos entre módulos. El JSON alimenta Consulta y Generador de armadura.
- Propiedades permite leer DWG individuales del proyecto además de carpetas completas.
- Traslada la conexión e integración AutoCAD/ZWCAD a Diagnóstico.
- Conserva las confirmaciones y la protección de borradores al cambiar de pestaña.

Los archivos permanecen locales. La lista de referencias dura mientras la aplicación esté abierta; quitar una referencia no elimina el archivo. Incorporar documentos no ejecuta OCR ni modifica DWG. Las carpetas de salida se seleccionan explícitamente.

Validación: 280 pruebas aprobadas (13 omitidas por requerir entornos nativos explícitos), 23 subpruebas y cuatro comprobaciones de interfaz de navegación, archivos compartidos, DWGPROPS y revisiones. Se verificó que el ejecutable incluye los nuevos archivos de interfaz. No se modificaron planos originales para estas pruebas.

## Instalación

Instalador firmado para Windows x64. Cierra SINCAL y CAD antes de instalar. La descarga de los paquetes requiere Internet.
