# SINCAL Suite 3.0.8 — Actualización de recursos CAD

- Corrige el error «Tamaño inesperado» al reutilizar archivos locales con saltos de línea de Windows. Conserva la verificación del tamaño y SHA de los bytes publicados.
- Incluye VG para eliminar bloques cuyo nombre comienza con VIÑETA en Modelo y layouts y ejecutar PURGEALL; respeta capas bloqueadas y referencias externas.
- Conserva las herramientas de revisiones, DWGPROPS y la integración con el Explorador de la versión 3.0.7.

Instala Setup_SINCAL_v3.0.8.exe y reinicia SINCAL y CAD. Requiere Windows x64 y conexión para descargar los paquetes. La instalación no modifica los planos.
