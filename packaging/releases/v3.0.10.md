# SINCAL Suite 3.0.10 — Carga de informes IMS

- Corrige el error `'function' object has no attribute 'is_set'` al cargar un PDF desde Prospecciones: el lector recibe el objeto de cancelación esperado.
- Una lectura cancelada se registra como cancelada y no como un fallo inesperado.
- Añade pruebas de integración del servicio web con un PDF sintético real: extracción de perfiles, cancelación durante la lectura y conservación del archivo original.
- Conserva las protecciones de viewports y las correcciones de procesamiento masivo de 3.0.9.

Instala Setup_SINCAL_v3.0.10.exe. La instalación no modifica los informes ni los planos del usuario.
