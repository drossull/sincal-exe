Pasarela BIM se incorpora a SINCAL como módulo opcional, situado encima de Generador de armadura.

- Si falta el módulo, el menú muestra **Pasarela BIM · No instalado**. Al entrar, **Instalar Pasarela BIM** descarga y verifica el paquete compatible con esta versión.
- La instalación es opcional y puede hacerse después de instalar el programa general. También se admite un ZIP local.
- Editor de pasarelas de hormigón con conexiones topológicas, proyectos JSON intercambiables, secciones editables, apoyos y fundaciones compartidas.
- Ejes de atravieso, recorridos y apoyos; movimiento coordinado de elementos y elevaciones por eje.
- Rampas con pendiente fija del 8 % como regla del editor; vista previa de ajustes geométricos.
- Generación del modelo BIM en FreeCAD y vistas iniciales para preparar planos.

**Instalación:** descarga y ejecuta `Setup_SINCAL_v3.0.25.exe`. Pasarela BIM queda desmarcado por defecto; puedes instalarlo después desde el propio menú de SINCAL. FreeCAD se instala por separado para generar el modelo.

El editor es una primera versión de la herramienta. El modelo y las vistas requieren revisión profesional antes de producir planos definitivos; el módulo no realiza cálculo estructural ni certifica cumplimiento normativo.

Los archivos `release-manifest_v3.0.25.json` y `SHA256SUMS.txt` identifican los paquetes de esta publicación.
