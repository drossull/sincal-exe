Pasarela BIM se abre dentro de SINCAL, en el panel central, manteniendo el menú de la plataforma.

- El proyecto, la selección y el historial permanecen al cambiar de módulo y regresar.
- Pasarela BIM sigue siendo opcional y se carga cuando se utiliza.
- Las instalaciones anteriores del módulo muestran una opción para actualizar al editor integrado 0.3.1.
- Se conservan la importación y exportación de proyectos JSON y la generación de modelos y vistas mediante FreeCAD.
- La integración admite únicamente la instancia local de SINCAL que inició el editor.

Instala `Setup_SINCAL_v3.0.26.exe`. Puedes seleccionar Pasarela BIM durante la instalación o incorporarlo después desde el menú. FreeCAD se instala por separado.
