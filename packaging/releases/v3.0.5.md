# SINCAL Suite 3.0.5 — Editor DWGPROPS

- Nueva pestaña independiente para cargar una carpeta de DWG y editar propiedades personalizadas individualmente o por selección múltiple.
- Buscador, valores mixtos, creación de propiedades, valores vacíos y eliminación explícita. Solo se modifican los campos seleccionados.
- Conectores firmados para AutoCAD Core Console 2025 y 2027, sin usar los dibujos abiertos ni iniciar la interfaz completa de AutoCAD.
- Edición sobre copias temporales, verificación por reapertura, control de cambios externos y respaldo por archivo en SINCAL_Backups antes de reemplazar el original.
- Limpieza de DWL/DWL2 nuevos tras procesamiento masivo exitoso, únicamente si se obtiene acceso exclusivo al DWG. No se borran residuos anteriores ni archivos de planos abiertos.
- Documentación y registros por ejecución. La cancelación se atiende entre archivos y no revierte los ya guardados.
- El instalador registra los comandos de la aplicación en el PATH del usuario sin retirar la ruta CAD activa. Abre una ventana nueva de CMD después de instalar.

Validación: 203 pruebas generales aprobadas, prueba automatizada de interfaz y pruebas nativas de lectura/guardado individual y múltiple en AutoCAD 2025 y 2027 usando copias de prueba. No sustituye la revisión de planos de producción.

Instala Setup_SINCAL_v3.0.5.exe. Requiere Windows x64, WebView2 y conexión para descargar los paquetes del instalador. DWGPROPS requiere AutoCAD 2025 o 2027 instalado; no incluye soporte para ZWCAD. No se modifican los DWG al instalar.
